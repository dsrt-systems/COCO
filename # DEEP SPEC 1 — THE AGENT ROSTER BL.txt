## 1. AGENT TAXONOMY & ARCHITECTURAL CLASSIFICATION

COCO does not treat agents as conversational prompt wrappers. An Agent in COCO is a **typed, stateful, permission-bounded cognitive actor** defined by:

$$\text{Agent} = \{\text{Identity}, \text{Role}, \text{Methodology}, \text{Knowledge Bases}, \text{Tools}, \text{Constraints}, \text{Critic}, \text{Evaluation Rubric}\}$$

The agent taxonomy is strictly organized into **four operational tiers**, ensuring high throughput, deterministic execution, and clear separation of control plane vs. data plane.

## 2. TIER 1 — CORE GOVERNANCE AGENTS

Tier 1 agents form the **Cognitive Control Plane**. They are persistent, run continuously within the kernel loop, and govern the execution of all downstream directors and specialists.

```text
               ┌─────────────────────────────────────────┐
               │           A1 COCO DIRECTOR              │
               └────────────────────┬────────────────────┘
                                    │
         ┌──────────────────────────┼──────────────────────────┐
         ▼                          ▼                          ▼
┌─────────────────┐        ┌─────────────────┐        ┌─────────────────┐
│A2 MISSION PLANNER│        │  A6 RISK OFFICER │        │ A4 MEMORY MANAGER│
└────────┬────────┘        └────────┬────────┘        └────────┬────────┘
         │                          │                          │
         ▼                          ▼                          ▼
┌─────────────────┐        ┌─────────────────┐        ┌─────────────────┐
│A5 MODEL ROUTER  │        │A3 UNIVERSAL CRITIC│      │ A7 SYNTHESIS    │
└─────────────────┘        └─────────────────┘        └─────────────────┘
```

### A1 — COCO Director (The Orchestrator)
*   **Role:** Universal Mission Commander and Cognitive Executive.
*   **Responsibility:** Receives input from the Gateway, executes Perception and Intent Engines ($S1 \rightarrow S2$), sets Cognitive Depth ($D0-D6$), spawns Tier 2 Directors, and manages final delivery.
*   **Methodology:** Goal-Directed Intent Resolution & Dynamic Topology Construction.
*   **Model Requirement:** Tier-1 Frontier Reasoning Model (e.g., Claude 3.5 Sonnet / O1 / DeepSeek-R1 class).
*   **Permissions:** Read/Write Kernel State, Spawn Any Agent, Allocate Compute Envelope.
*   **Constraints:** Cannot execute raw tools directly; must delegate all execution to lower tiers.

### A2 — Mission Planner & Task Decomposer
*   **Role:** Directed Acyclic Graph (DAG) Engineer.
*   **Responsibility:** Receives objective from A1, executes S7 (Plan), decomposes missions into discrete, dependency-mapped tasks with explicit inputs, outputs, success criteria, and verification levels ($L0-L10$).
*   **Methodology:** Hierarchical Task Network (HTN) Planning & Critical Path Analysis.
*   **Model Requirement:** High-Context Reasoning & Structured Output Specialist.
*   **Permissions:** Write TaskGraph, Read ProjectBrain.
*   **Constraints:** Tasks must be granular enough for single-agent execution; must enforce DAG validity (no cycles).

### A3 — Universal Critic & Red Team
*   **Role:** Adversarial Quality Controller.
*   **Responsibility:** Executes S10 (Critique), applies $L9$ verification, attacks claims, attempts to break code/architecture, surfaces hidden assumptions, and enforces the COCO Standards.
*   **Methodology:** Red-Teaming, Fuzz Reasoning, Socratic Stress-Testing.
*   **Model Requirement:** Frontier Reasoning Model configured for Adversarial Critique.
*   **Permissions:** Reject Any Artifact, Issue Repair Orders, Halt Execution.
*   **Constraints:** Must provide concrete, actionable root-cause diagnoses for every rejection.

### A4 — Memory & Context Manager
*   **Role:** Information Synthesizer & Knowledge Graph Custodian.
*   **Responsibility:** Executes S3 (Recall) and S4 (Context Build), queries 7 memory scopes, calculates memory relevance, compresses context packets, and writes back to ProjectBrain at S14.
*   **Methodology:** Vector-Graph Hybrid Retrieval, Recency-Importance-Relevance Decay Scoring.
*   **Model Requirement:** Long-Context Retrieval & Summarization Model.
*   **Permissions:** Read/Write Memory Scopes, Access Vector Index & Knowledge Graph.
*   **Constraints:** Enforce zero context leakage between tenants; must store provenance with every memory record.

### A5 — Model & Intelligence Router
*   **Role:** Computational Substrate Optimizer.
*   **Responsibility:** Analyzes task complexity, latency, context size, and budget, routing each task to the optimal model (Open-Weight, Local vLLM, or Hosted Frontier API).
*   **Methodology:** Multi-Armed Bandit with Cost-Quality-Latency Pareto Optimization.
*   **Model Requirement:** Lightweight Deterministic Classifier / Fast Sub-second Model.
*   **Permissions:** Read Model Registry, Assign Model Adapters.
*   **Constraints:** Never exceed mission compute envelope; enforce provider fallback chains on error.

### A6 — Risk, Safety & Compliance Officer
*   **Role:** Boundary Enforcer & Security Authority.
*   **Responsibility:** Monitors real-time events for safety violations, permission overrides, data leakages, destructive execution, and budget exhaustion.
*   **Methodology:** Deterministic Policy Checking, Static Rule Parsing, Anomaly Detection.
*   **Model Requirement:** Deterministic Rule Engine + Guardrail LLM Classifier.
*   **Permissions:** Global Kill Switch, Revoke Tool Permissions, Force Human-in-the-Loop Gate.
*   **Constraints:** Overrides A1 Director if a hard constitutional safety rule is violated.

### A7 — Synthesis & Delivery Agent
*   **Role:** Deliverable Architect & Response Composer.
*   **Responsibility:** Receives verified artifacts, applies S13 (Compose Response), selects the appropriate Response Mode (Direct, Reasoned, Investigative, Mission Report, etc.), and formats outputs to the COCO Voice Standard.
*   **Methodology:** COCO Voice Protocol, Structured Markdown/Artifact Packaging.
*   **Model Requirement:** High-Precision Natural Language Generation Model.
*   **Permissions:** Read Verified Artifacts, Write Final Output Stream.
*   **Constraints:** Strictly eliminate corporate slop, fluff, and unevidenced claims.

### A8 — Evolution & Telemetry Evaluator
*   **Role:** System Performance Analyst.
*   **Responsibility:** Post-mission, analyzes event logs, compares planned vs. actual resource utilization, grades agent accuracy, and writes performance vectors to the Evolution Fabric.
*   **Methodology:** Offline Telemetry Aggregation, Reinforcement Learning Signal Generation.
*   **Model Requirement:** Offline Data Analysis Model / Batch Evaluator.
*   **Permissions:** Read Full Mission Event Store, Write System Metrics.
*   **Constraints:** Runs asynchronously; cannot block real-time mission execution.

## 6. THE AGENT CONTRACT & SCHEMAS

Every agent definition in COCO must parse against this strict **OpenAPI / Pydantic V2 Schema**. Definitions that fail validation are rejected at boot time.

```python
from enum import Enum
from typing import List, Dict, Optional, Any
from pydantic import BaseModel, Field, HttpUrl

class AgentTier(str, Enum):
    TIER_1_CORE = "tier_1_core"
    TIER_2_DIRECTOR = "tier_2_director"
    TIER_3_SPECIALIST = "tier_3_specialist"
    TIER_4_OPERATOR = "tier_4_operator"

class ToolScope(str, Enum):
    READ_ONLY = "read_only"
    WORKSPACE_WRITE = "workspace_write"
    COMPUTE_EXEC = "compute_exec"
    SANDBOX_EXEC = "sandbox_exec"
    NETWORK_EGRESS = "network_egress"

class AgentToolRequirement(BaseModel):
    tool_id: str
    scope: ToolScope
    is_required: bool = True

class ModelProfile(BaseModel):
    reasoning_model: str = Field(description="Identifier for preferred reasoning LLM")
    fallback_models: List[str] = Field(default_factory=list)
    temperature: float = Field(default=0.0, ge=0.0, le=1.0)
    max_context_tokens: int = Field(default=128000)

class AgentConstraints(BaseModel):
    must_rules: List[str] = Field(description="Rules the agent must strictly follow")
    must_not_rules: List[str] = Field(description="Banned actions/patterns")
    requires_human_approval: List[str] = Field(default_factory=list)

class EvaluationRubric(BaseModel):
    metrics: Dict[str, float] = Field(description="Metric name to minimum passing score")
    rejection_threshold: float = Field(default=0.85, ge=0.0, le=1.0)

class AgentDefinitionContract(BaseModel):
    """Immutable contract defining an agent in the COCO Ecosystem."""
    agent_id: str = Field(pattern=r"^[A-Z][0-9]+_[a-z0-9_]+$")
    name: str
    version: str = "1.0.0"
    tier: AgentTier
    domain: str
    reports_to: Optional[str] = None
    
    expert_beating_thesis: str = Field(description="Concrete reason why this agent beats median human experts")
    model_profile: ModelProfile
    knowledge_sources: List[str]
    tool_suite: List[AgentToolRequirement]
    
    system_prompt_template: str
    methodology_framework: str
    methodology_steps: List[str]
    
    constraints: AgentConstraints
    critic_agent_id: Optional[str] = None
    evaluation_rubric: EvaluationRubric
    
    allowed_memory_scopes: List[str]
```

## 7. DYNAMIC AGENT FACTORY & SPAWNING ENGINE

While COCO registers 134 flagship capabilities statically, missions often require **niche, hyper-specific expertise** (e.g., *"Sanskrit Manuscript Specialist"* or *"1970s COBOL Mainframe Migration Specialist"*).

Instead of hardcoding every micro-domain, Tier 2 Directors use the **Dynamic Agent Factory** to compile and spawn custom Tier 3 Specialists at runtime.

```text
                        MISSION REQUIREMENT
                    "Analyze 18th Century Maratha 
                     Land Revenue Documents"
                               │
                               ▼
                    TIER 2 RESEARCH DIRECTOR
                               │
                               ▼
                  IS CAPABILITY IN REGISTRY?
                               │
                      ┌────────┴────────┐
                      │                 │
                    YES                 NO
                      │                 │
                      ▼                 ▼
               USE REGISTERED    AGENT FACTORY
                  SPECIALIST      COMPILATION
                                        │
                                        ▼
                               1. Fetch Domain Corpus
                               2. Assemble Tool Suite
                               3. Select Base Model
                               4. Inject Methodology
                               5. Instantiate Critic
                                        │
                                        ▼
                               SPAWN DYNAMIC AGENT
                               C135_maratha_revenue_spec
```

### The Factory Spawning Algorithm

```python
class DynamicAgentFactory:
    """Compiles and registers ad-hoc Tier-3 specialists at runtime."""
    
    def __init__(self, registry: AgentRegistry, knowledge_engine: KnowledgeEngine):
        self.registry = registry
        self.knowledge = knowledge_engine

    async def spawn_specialist(
        self, 
        domain_name: str, 
        task_requirements: TaskRequirements, 
        parent_director_id: str
    ) -> AgentDefinitionContract:
        
        # 1. Synthesize domain knowledge corpus
        corpus = await self.knowledge.retrieve_domain_corpus(domain_name)
        
        # 2. Derive domain methodology & constraints
        methodology = await self.derive_methodology(domain_name, task_requirements)
        
        # 3. Create paired Adversarial Critic definition
        critic_id = f"critic_dynamic_{domain_name.lower()}"
        critic_def = self.build_dynamic_critic(critic_id, domain_name, methodology)
        await self.registry.register(critic_def)
        
        # 4. Construct Agent Definition Contract
        agent_id = f"C_dynamic_{domain_name.lower()}_{hash(task_requirements.objective)[:6]}"
        agent_contract = AgentDefinitionContract(
            agent_id=agent_id,
            name=f"Dynamic Specialist: {domain_name}",
            tier=AgentTier.TIER_3_SPECIALIST,
            domain=domain_name,
            reports_to=parent_director_id,
            expert_beating_thesis=f"Dynamically compiled specialist for {domain_name} using primary corpus and strict verification.",
            model_profile=ModelProfile(
                reasoning_model="frontier-reasoning-high",
                temperature=0.0
            ),
            knowledge_sources=corpus.source_identifiers,
            tool_suite=task_requirements.required_tools,
            system_prompt_template=f"You are the world's leading specialist in {domain_name}...",
            methodology_framework=methodology.framework_name,
            methodology_steps=methodology.steps,
            constraints=AgentConstraints(
                must_rules=methodology.must_rules,
                must_not_rules=methodology.must_not_rules
            ),
            critic_agent_id=critic_id,
            evaluation_rubric=EvaluationRubric(
                metrics={"accuracy": 0.90, "domain_fidelity": 0.95},
                rejection_threshold=0.88
            ),
            allowed_memory_scopes=["working", "project", "semantic"]
        )
        
        # 5. Register in active runtime memory
        await self.registry.register(agent_contract)
        return agent_contract
```
