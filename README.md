# COCO

An autonomous intelligence organization that accepts human missions, assembles world-class expert agents, executes verified work, and produces professional deliverables.

## Status

**Phase 0 — Foundation & Repo Bootstrap**

## Stack

- **Next.js 15** (App Router, RSC, Server Actions)
- **Supabase** (Postgres + pgvector + Auth + Realtime + Storage)
- **Upstash Redis** (Cache, rate limiting, streams)
- **Model Providers:** Anthropic, OpenAI, Google, DeepSeek, Groq, OpenRouter
- **E2B** (Sandboxed code execution)
- **Langfuse** (LLM observability)
- **Vercel** (Hosting, Cron, Edge Functions)
