# DEEP SPEC 3 — THE DATABASE SCHEMA

**System:** DSRT COCO
**Layer:** Persistence & Data Fabric
**Status:** Approved & Locked Specification
**Governing Standards:** Constitutional Dimensions 3 (Object Model), 8 (Memory Model); Article XIII; Deep Specs 1 & 2
**Target Engine:** PostgreSQL 16+ with pgvector 0.7+, pg_partman, pg_trgm, pgcrypto

---

## 0. SCHEMA PHILOSOPHY

The database is not storage. **The database is the source of truth for COCO's memory, mission state, and history.** Every read, write, and query must be:

```text
LAW 1  — MULTI-TENANT ISOLATED
         Every tenant-scoped row carries organization_id and is protected by RLS.
         Cross-tenant leakage is a hard security failure.

LAW 2  — IMMUTABLE BY DEFAULT
         Events, decisions, agent runs, model calls, tool calls, verifications
         are append-only. Corrections come as new rows, never mutations.

LAW 3  — PROVENANCE-ATTACHED
         Every knowledge row carries source, agent_id, confidence, timestamps.
         No memory exists without lineage.

LAW 4  — REFERENTIALLY TRACEABLE
         Every derived row references the mission_id, run_id, and (where applicable)
         the causation event_id. Full mission replay must be possible from the DB alone.

LAW 5  — PARTITION EARLY
         High-volume tables (events, model_calls, tool_calls) are partitioned from day 1.
         Retention policies are declared at schema creation, not bolted on later.

LAW 6  — INDEX FOR QUERIES, NOT GUESSES
         Every index has a documented query. Unused indexes are removed.
         BRIN for time-series, HNSW for vectors, GIN for JSONB/trgm.

LAW 7  — VERSIONED MIGRATIONS
         Every schema change is a versioned, reversible migration.
         Zero-downtime deploys are non-negotiable.

LAW 8  — TIME IS UTC AND NANOSECONDS
         All timestamps are TIMESTAMPTZ. Event ordering uses BIGINT unix_ns
         to match Protocol Envelope semantics.

LAW 9  — SIZE-BOUNDED ROWS
         Large payloads (artifacts, logs, context packets) live in object storage.
         Postgres holds references, hashes, metadata — never blobs > 1MB.

LAW 10 — SCHEMA IS EXECUTABLE CONSTITUTION
         The DDL below is version-controlled, code-reviewed, and enforced
         by CI. No production write bypasses the schema.
```

## 1. DATABASE TOPOLOGY

COCO uses **schema-per-concern isolation** within a single logical database, enabling independent scaling, backups, and future physical separation.

```text
┌────────────────────────────────────────────────────────────────────┐
│                        coco (logical database)                     │
├────────────────────────────────────────────────────────────────────┤
│  SCHEMA: identity         → users, orgs, memberships, sessions     │
│  SCHEMA: projects         → projects, project_settings             │
│  SCHEMA: missions         → missions, tasks, task_edges, checkpts  │
│  SCHEMA: agents           → agent_defs, instances, runs, findings  │
│  SCHEMA: models           → model_registry, model_calls            │
│  SCHEMA: tools            → tool_registry, tool_calls, sandboxes   │
│  SCHEMA: memory           → memories (7 scopes), context_packets   │
│  SCHEMA: brain            → project_brain, knowledge nodes/edges   │
│  SCHEMA: research         → sources, evidence, citations           │
│  SCHEMA: artifacts        → artifact metadata (blobs in S3)        │
│  SCHEMA: verification     → verifications, level_results, critics  │
│  SCHEMA: security         → capability_tokens, approvals, audit    │
│  SCHEMA: events           → event log (partitioned monthly)        │
│  SCHEMA: evolution        → metrics, evaluations, route_policies   │
│  SCHEMA: billing          → usage, invoices, subscriptions         │
├────────────────────────────────────────────────────────────────────┤
│  EXTENSIONS: vector, pg_partman, pg_trgm, pgcrypto, btree_gin,     │
│              pg_stat_statements, ltree                             │
└────────────────────────────────────────────────────────────────────┘
```

### Extensions & Baseline Setup

```sql
-- ═══════════════════════════════════════════════════════════════════
-- COCO DATABASE — BASELINE INITIALIZATION
-- ═══════════════════════════════════════════════════════════════════

CREATE DATABASE coco
  WITH ENCODING = 'UTF8'
       LC_COLLATE = 'en_US.UTF-8'
       LC_CTYPE = 'en_US.UTF-8'
       TEMPLATE = template0;

\c coco

CREATE EXTENSION IF NOT EXISTS "pgcrypto";       -- gen_random_uuid, digest
CREATE EXTENSION IF NOT EXISTS "vector";         -- pgvector for embeddings
CREATE EXTENSION IF NOT EXISTS "pg_partman";     -- automated partitioning
CREATE EXTENSION IF NOT EXISTS "pg_trgm";        -- fuzzy text search
CREATE EXTENSION IF NOT EXISTS "btree_gin";      -- multi-column GIN
CREATE EXTENSION IF NOT EXISTS "ltree";          -- hierarchical paths
CREATE EXTENSION IF NOT EXISTS "pg_stat_statements";

-- ─── ROLES ─────────────────────────────────────────────────────────
CREATE ROLE coco_owner      NOLOGIN;
CREATE ROLE coco_migrator   LOGIN PASSWORD :migrator_pw;
CREATE ROLE coco_app        LOGIN PASSWORD :app_pw;      -- kernel + fabrics
CREATE ROLE coco_readonly   LOGIN PASSWORD :ro_pw;       -- observability
CREATE ROLE coco_tenant     NOLOGIN;                     -- template for RLS

GRANT coco_owner TO coco_migrator;

-- ─── SCHEMAS ───────────────────────────────────────────────────────
CREATE SCHEMA identity      AUTHORIZATION coco_owner;
CREATE SCHEMA projects      AUTHORIZATION coco_owner;
CREATE SCHEMA missions      AUTHORIZATION coco_owner;
CREATE SCHEMA agents        AUTHORIZATION coco_owner;
CREATE SCHEMA models        AUTHORIZATION coco_owner;
CREATE SCHEMA tools         AUTHORIZATION coco_owner;
CREATE SCHEMA memory        AUTHORIZATION coco_owner;
CREATE SCHEMA brain         AUTHORIZATION coco_owner;
CREATE SCHEMA research      AUTHORIZATION coco_owner;
CREATE SCHEMA artifacts     AUTHORIZATION coco_owner;
CREATE SCHEMA verification  AUTHORIZATION coco_owner;
CREATE SCHEMA security      AUTHORIZATION coco_owner;
CREATE SCHEMA events        AUTHORIZATION coco_owner;
CREATE SCHEMA evolution     AUTHORIZATION coco_owner;
CREATE SCHEMA billing       AUTHORIZATION coco_owner;

GRANT USAGE ON SCHEMA identity, projects, missions, agents, models, tools,
                       memory, brain, research, artifacts, verification,
                       security, events, evolution, billing
  TO coco_app, coco_readonly;

-- ─── SHARED DOMAINS (typed primitives) ─────────────────────────────
CREATE DOMAIN ulid AS CHAR(26)
  CHECK (VALUE ~ '^[0-9A-HJKMNP-TV-Z]{26}$');

CREATE DOMAIN sha256_hex AS CHAR(64)
  CHECK (VALUE ~ '^[0-9a-f]{64}$');

CREATE DOMAIN confidence_score AS DOUBLE PRECISION
  CHECK (VALUE >= 0.0 AND VALUE <= 1.0);

CREATE DOMAIN percent AS DOUBLE PRECISION
  CHECK (VALUE >= 0.0 AND VALUE <= 100.0);

CREATE DOMAIN money_usd AS NUMERIC(14,6)
  CHECK (VALUE >= 0);

-- ─── SHARED ENUMS ──────────────────────────────────────────────────
CREATE TYPE mission_tier     AS ENUM ('default','pro','ranger','enterprise');
CREATE TYPE mission_phase    AS ENUM (
  'created','understanding','challenging','researching','planning',
  'organizing','executing','verifying','repairing','refining',
  'delivering','remembering','completed','operating','cancelled','failed');
CREATE TYPE task_kind        AS ENUM (
  'reason','research','plan','code','execute','analyze',
  'design','verify','deliver','decide','clarify');
CREATE TYPE task_status      AS ENUM (
  'pending','ready','assigned','running','verifying',
  'repairing','completed','blocked','failed','cancelled');
CREATE TYPE agent_tier       AS ENUM (
  'tier_1_core','tier_2_director','tier_3_specialist','tier_4_operator');
CREATE TYPE autonomy_level   AS ENUM (
  'l0_answer','l1_recommend','l2_reversible','l3_multistep',
  'l4_checkpointed','l5_continuous');
CREATE TYPE run_outcome      AS ENUM (
  'completed_success','completed_partial','blocked_info_needed',
  'failed_unrecoverable','aborted_budget_exceeded',
  'aborted_policy_violation','escalated_to_human');
CREATE TYPE epistemic_status AS ENUM (
  'fact','supported','inferred','weak_inference',
  'assumed','unknown','contested');
CREATE TYPE memory_scope     AS ENUM (
  'working','conversation','episodic','semantic',
  'procedural','project','organizational');
CREATE TYPE memory_status    AS ENUM (
  'active','superseded','contradicted','archived');
CREATE TYPE access_mode      AS ENUM ('read','write','read_write');
CREATE TYPE verdict          AS ENUM (
  'accepted','accepted_with_notes','rejected',
  'repair_required','escalate_human','insufficient_info');
CREATE TYPE sensitivity      AS ENUM (
  'public','internal','confidential','restricted');
CREATE TYPE error_category   AS ENUM (
  'unknown','logic','dependency','config','environment','integration',
  'requirement','security','performance','network','permission');
CREATE TYPE tool_status      AS ENUM (
  'success','failure_tool','failure_timeout','failure_oom',
  'failure_policy','failure_permission','failure_sandbox',
  'awaiting_approval','cancelled');
```

## 2. THE IDENTITY SCHEMA

```sql
-- ═══════════════════════════════════════════════════════════════════
-- SCHEMA: identity — Users, Organizations, Memberships, Sessions
-- ═══════════════════════════════════════════════════════════════════
SET search_path TO identity, public;

CREATE TABLE organizations (
  organization_id   ulid PRIMARY KEY,
  slug              TEXT NOT NULL UNIQUE,
  display_name      TEXT NOT NULL,
  tier              mission_tier NOT NULL DEFAULT 'default',
  billing_email     TEXT,
  region            TEXT NOT NULL DEFAULT 'us-east-1',
  encryption_key_id TEXT,                          -- KMS ref for RESTRICTED data
  settings          JSONB NOT NULL DEFAULT '{}'::jsonb,
  metadata          JSONB NOT NULL DEFAULT '{}'::jsonb,
  created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at        TIMESTAMPTZ
);

CREATE INDEX org_slug_idx ON organizations (slug) WHERE deleted_at IS NULL;
CREATE INDEX org_tier_idx ON organizations (tier)  WHERE deleted_at IS NULL;

CREATE TABLE users (
  user_id           ulid PRIMARY KEY,
  primary_email     TEXT NOT NULL UNIQUE,
  display_name      TEXT NOT NULL,
  auth_provider     TEXT NOT NULL,                 -- 'email', 'google', 'github', 'sso'
  auth_subject      TEXT NOT NULL,                 -- provider's stable user ID
  preferences       JSONB NOT NULL DEFAULT '{}'::jsonb,
  metadata          JSONB NOT NULL DEFAULT '{}'::jsonb,
  last_seen_at      TIMESTAMPTZ,
  created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  deleted_at        TIMESTAMPTZ,
  UNIQUE (auth_provider, auth_subject)
);

CREATE TABLE memberships (
  membership_id     ulid PRIMARY KEY,
  organization_id   ulid NOT NULL REFERENCES organizations(organization_id),
  user_id           ulid NOT NULL REFERENCES users(user_id),
  role              TEXT NOT NULL CHECK (role IN ('owner','admin','member','viewer','service')),
  permissions       JSONB NOT NULL DEFAULT '{}'::jsonb,
  invited_by        ulid REFERENCES users(user_id),
  joined_at         TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  revoked_at        TIMESTAMPTZ,
  UNIQUE (organization_id, user_id)
);

CREATE INDEX membership_user_idx ON memberships (user_id) WHERE revoked_at IS NULL;
CREATE INDEX membership_org_role_idx ON memberships (organization_id, role) WHERE revoked_at IS NULL;

CREATE TABLE sessions (
  session_id        ulid PRIMARY KEY,
  user_id           ulid NOT NULL REFERENCES users(user_id),
  organization_id   ulid NOT NULL REFERENCES organizations(organization_id),
  client_context    JSONB NOT NULL DEFAULT '{}'::jsonb,   -- user-agent, IP prefix, surface
  refresh_token_hash sha256_hex NOT NULL,
  issued_at         TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  expires_at        TIMESTAMPTZ NOT NULL,
  revoked_at        TIMESTAMPTZ
);

CREATE INDEX session_user_active_idx ON sessions (user_id, expires_at DESC)
  WHERE revoked_at IS NULL;
```

## 3. THE PROJECTS SCHEMA

```sql
-- ═══════════════════════════════════════════════════════════════════
-- SCHEMA: projects — Long-lived container above missions
-- ═══════════════════════════════════════════════════════════════════
SET search_path TO projects, public;

CREATE TABLE projects (
  project_id        ulid PRIMARY KEY,
  organization_id   ulid NOT NULL REFERENCES identity.organizations(organization_id),
  slug              TEXT NOT NULL,
  display_name      TEXT NOT NULL,
  description       TEXT,
  status            TEXT NOT NULL DEFAULT 'active'
                    CHECK (status IN ('active','paused','archived','deleted')),
  visibility        TEXT NOT NULL DEFAULT 'private'
                    CHECK (visibility IN ('private','organization','public')),
  primary_domain    TEXT,                            -- e.g. "software", "legal", "medical"
  tech_stack        JSONB NOT NULL DEFAULT '[]'::jsonb,
  settings          JSONB NOT NULL DEFAULT '{}'::jsonb,
  metadata          JSONB NOT NULL DEFAULT '{}'::jsonb,
  created_by        ulid NOT NULL REFERENCES identity.users(user_id),
  created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  archived_at       TIMESTAMPTZ,
  UNIQUE (organization_id, slug)
);

CREATE INDEX project_org_status_idx ON projects (organization_id, status);
CREATE INDEX project_domain_idx     ON projects (primary_domain) WHERE status = 'active';

CREATE TABLE project_members (
  project_id        ulid NOT NULL REFERENCES projects(project_id) ON DELETE CASCADE,
  user_id           ulid NOT NULL REFERENCES identity.users(user_id),
  role              TEXT NOT NULL CHECK (role IN ('owner','editor','viewer')),
  added_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  PRIMARY KEY (project_id, user_id)
);
```

## 4. THE MISSIONS SCHEMA

```sql
-- ═══════════════════════════════════════════════════════════════════
-- SCHEMA: missions — Missions, TaskGraphs, Tasks, Checkpoints
-- ═══════════════════════════════════════════════════════════════════
SET search_path TO missions, public;

CREATE TABLE missions (
  mission_id            ulid PRIMARY KEY,
  organization_id       ulid NOT NULL REFERENCES identity.organizations(organization_id),
  project_id            ulid REFERENCES projects.projects(project_id),
  parent_mission_id     ulid REFERENCES missions(mission_id),
  created_by            ulid NOT NULL REFERENCES identity.users(user_id),

  objective             TEXT NOT NULL,
  normalized_intent     TEXT,
  success_criteria      JSONB NOT NULL DEFAULT '[]'::jsonb,
  constraints           JSONB NOT NULL DEFAULT '[]'::jsonb,

  tier                  mission_tier NOT NULL,
  cognitive_depth       SMALLINT NOT NULL CHECK (cognitive_depth BETWEEN 0 AND 6),
  autonomy_level        autonomy_level NOT NULL DEFAULT 'l1_recommend',
  delivery_mode         TEXT NOT NULL CHECK (delivery_mode IN ('sync','async','streaming','checkpointed')),
  deliverable_types     TEXT[] NOT NULL DEFAULT '{}',

  budget                JSONB NOT NULL DEFAULT '{}'::jsonb,      -- ResourceBudget
  usage                 JSONB NOT NULL DEFAULT '{}'::jsonb,      -- ResourceUsage rolling

  phase                 mission_phase NOT NULL DEFAULT 'created',
  current_step          TEXT,                                    -- S1..S15
  progress_percent      percent NOT NULL DEFAULT 0.0,
  status_summary        TEXT,

  started_at            TIMESTAMPTZ,
  last_activity_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  estimated_completion_at TIMESTAMPTZ,
  completed_at          TIMESTAMPTZ,

  created_at            TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at            TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX mission_org_active_idx    ON missions (organization_id, phase)
  WHERE phase NOT IN ('completed','failed','cancelled');
CREATE INDEX mission_project_idx       ON missions (project_id, created_at DESC);
CREATE INDEX mission_user_recent_idx   ON missions (created_by, created_at DESC);
CREATE INDEX mission_last_activity_idx ON missions (last_activity_at DESC)
  WHERE phase NOT IN ('completed','failed','cancelled');

CREATE TABLE task_graphs (
  graph_id          ulid PRIMARY KEY,
  mission_id        ulid NOT NULL REFERENCES missions(mission_id) ON DELETE CASCADE,
  graph_version     INT NOT NULL DEFAULT 1,
  critical_path     TEXT,                             -- comma-separated task_ids
  created_by_agent  TEXT NOT NULL,                    -- typically A2_mission_planner
  created_at        TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  superseded_at     TIMESTAMPTZ,
  UNIQUE (mission_id, graph_version)
);

CREATE INDEX task_graph_current_idx ON task_graphs (mission_id)
  WHERE superseded_at IS NULL;

CREATE TABLE tasks (
  task_id                  ulid PRIMARY KEY,
  mission_id               ulid NOT NULL REFERENCES missions(mission_id) ON DELETE CASCADE,
  graph_id                 ulid NOT NULL REFERENCES task_graphs(graph_id),
  parent_task_id           ulid REFERENCES tasks(task_id),

  objective                TEXT NOT NULL,
  kind                     task_kind NOT NULL,

  required_capabilities    TEXT[] NOT NULL DEFAULT '{}',
  preferred_agent_id       TEXT,
  assigned_agent_instance  ulid,

  input_artifact_refs      TEXT[] NOT NULL DEFAULT '{}',
  expected_outputs         JSONB NOT NULL DEFAULT '[]'::jsonb,

  verification_level       SMALLINT NOT NULL DEFAULT 6 CHECK (verification_level BETWEEN 0 AND 10),
  cognitive_depth          SMALLINT NOT NULL CHECK (cognitive_depth BETWEEN 0 AND 6),
  task_budget              JSONB NOT NULL DEFAULT '{}'::jsonb,

  success_criteria         JSONB NOT NULL DEFAULT '[]'::jsonb,
  max_repair_attempts      SMALLINT NOT NULL DEFAULT 3,
  attempt_number           SMALLINT NOT NULL DEFAULT 0,

  status                   task_status NOT NULL DEFAULT 'pending',
  status_reason            TEXT,

  started_at               TIMESTAMPTZ,
  completed_at             TIMESTAMPTZ,
  created_at               TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at               TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX task_mission_status_idx ON tasks (mission_id, status);
CREATE INDEX task_ready_idx          ON tasks (mission_id, status)
  WHERE status IN ('ready','running','repairing');
CREATE INDEX task_agent_idx          ON tasks (assigned_agent_instance)
  WHERE assigned_agent_instance IS NOT NULL;

CREATE TABLE task_edges (
  edge_id           ulid PRIMARY KEY,
  graph_id          ulid NOT NULL REFERENCES task_graphs(graph_id) ON DELETE CASCADE,
  from_task_id      ulid NOT NULL REFERENCES tasks(task_id) ON DELETE CASCADE,
  to_task_id        ulid NOT NULL REFERENCES tasks(task_id) ON DELETE CASCADE,
  kind              TEXT NOT NULL CHECK (kind IN ('depends_on','feeds','triggers','conditional')),
  condition_expr    TEXT,                             -- for conditional edges
  UNIQUE (graph_id, from_task_id, to_task_id, kind)
);

CREATE INDEX task_edge_from_idx ON task_edges (from_task_id);
CREATE INDEX task_edge_to_idx   ON task_edges (to_task_id);

-- DAG integrity check (no self-loops; broader cycle check enforced at write time in app)
ALTER TABLE task_edges
  ADD CONSTRAINT task_edge_no_self_loop CHECK (from_task_id <> to_task_id);

CREATE TABLE checkpoints (
  checkpoint_id       ulid PRIMARY KEY,
  mission_id          ulid NOT NULL REFERENCES missions(mission_id) ON DELETE CASCADE,
  checkpoint_number   INT NOT NULL,
  checkpoint_hash     sha256_hex NOT NULL,
  reason              TEXT NOT NULL,                  -- 'scheduled','phase_transition','risk_gate'

  state_snapshot_uri  TEXT NOT NULL,                  -- s3:// or coco://
  graph_snapshot_uri  TEXT NOT NULL,
  context_snapshot_uri TEXT,

  artifact_refs       TEXT[] NOT NULL DEFAULT '{}',
  size_bytes          BIGINT,
  created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (mission_id, checkpoint_number)
);

CREATE INDEX checkpoint_mission_recent_idx ON checkpoints (mission_id, checkpoint_number DESC);
```

## 5. THE AGENTS SCHEMA

```sql
-- ═══════════════════════════════════════════════════════════════════
-- SCHEMA: agents — Definitions, Instances, Runs, Findings, Decisions
-- ═══════════════════════════════════════════════════════════════════
SET search_path TO agents, public;

-- Static + dynamically-registered agent definitions
CREATE TABLE agent_definitions (
  agent_definition_id   TEXT PRIMARY KEY,             -- e.g. "C36_legal_corporate_attorney"
  version               TEXT NOT NULL,
  tier                  agent_tier NOT NULL,
  domain                TEXT NOT NULL,
  reports_to            TEXT REFERENCES agent_definitions(agent_definition_id),
  display_name          TEXT NOT NULL,

  expert_beating_thesis TEXT NOT NULL,
  system_prompt_template TEXT NOT NULL,
  methodology_framework TEXT NOT NULL,
  methodology_steps     JSONB NOT NULL,               -- ordered array

  model_profile         JSONB NOT NULL,               -- ModelProfile
  knowledge_sources     TEXT[] NOT NULL DEFAULT '{}',
  tool_suite            JSONB NOT NULL DEFAULT '[]'::jsonb,      -- AgentToolRequirement[]
  constraints           JSONB NOT NULL,               -- AgentConstraints
  critic_agent_id       TEXT REFERENCES agent_definitions(agent_definition_id),
  evaluation_rubric     JSONB NOT NULL,               -- EvaluationRubric
  allowed_memory_scopes memory_scope[] NOT NULL DEFAULT '{}',

  is_dynamic            BOOLEAN NOT NULL DEFAULT FALSE,
  dynamic_parent_domain TEXT,
  registered_at         TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  retired_at            TIMESTAMPTZ
);

CREATE INDEX agent_def_tier_idx     ON agent_definitions (tier);
CREATE INDEX agent_def_domain_idx   ON agent_definitions (domain);
CREATE INDEX agent_def_dynamic_idx  ON agent_definitions (is_dynamic, registered_at DESC);

-- Every spawn creates an instance (may run multiple runs across a mission)
CREATE TABLE agent_instances (
  agent_instance_id       ulid PRIMARY KEY,
  organization_id         ulid NOT NULL REFERENCES identity.organizations(organization_id),
  mission_id              ulid NOT NULL REFERENCES missions.missions(mission_id) ON DELETE CASCADE,
  agent_definition_id     TEXT NOT NULL REFERENCES agent_definitions(agent_definition_id),
  requesting_agent_id     TEXT,                       -- who spawned this
  parent_instance_id      ulid REFERENCES agent_instances(agent_instance_id),

  initial_context_ref     TEXT,                       -- ContextPacketRef
  tool_grants             JSONB NOT NULL DEFAULT '[]'::jsonb,
  memory_grants           JSONB NOT NULL DEFAULT '[]'::jsonb,
  model_preferences       JSONB NOT NULL DEFAULT '{}'::jsonb,
  budget                  JSONB NOT NULL DEFAULT '{}'::jsonb,

  status                  TEXT NOT NULL DEFAULT 'spawned'
                          CHECK (status IN ('spawned','running','paused','completed','failed','retired')),
  spawned_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  retired_at              TIMESTAMPTZ
);

CREATE INDEX agent_inst_mission_idx  ON agent_instances (mission_id, spawned_at DESC);
CREATE INDEX agent_inst_active_idx   ON agent_instances (mission_id)
  WHERE status IN ('spawned','running','paused');
CREATE INDEX agent_inst_definition_idx ON agent_instances (agent_definition_id);

-- Every task execution is a run (an instance may have multiple runs)
CREATE TABLE agent_runs (
  run_id                  ulid PRIMARY KEY,
  organization_id         ulid NOT NULL REFERENCES identity.organizations(organization_id),
  mission_id              ulid NOT NULL REFERENCES missions.missions(mission_id) ON DELETE CASCADE,
  task_id                 ulid NOT NULL REFERENCES missions.tasks(task_id) ON DELETE CASCADE,
  agent_instance_id       ulid NOT NULL REFERENCES agent_instances(agent_instance_id),
  agent_definition_id     TEXT NOT NULL REFERENCES agent_definitions(agent_definition_id),

  outcome                 run_outcome,
  outcome_summary         TEXT,

  confidence_overall      confidence_score,
  confidence_reasoning    TEXT,
  caveats                 TEXT[] NOT NULL DEFAULT '{}',
  requires_human_review   BOOLEAN NOT NULL DEFAULT FALSE,

  assumptions_made        JSONB NOT NULL DEFAULT '[]'::jsonb,
  open_questions          JSONB NOT NULL DEFAULT '[]'::jsonb,
  next_recommended_tasks  JSONB NOT NULL DEFAULT '[]'::jsonb,

  usage                   JSONB NOT NULL DEFAULT '{}'::jsonb,   -- ResourceUsage

  started_at              TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  completed_at            TIMESTAMPTZ
);

CREATE INDEX agent_run_mission_idx     ON agent_runs (mission_id, started_at DESC);
CREATE INDEX agent_run_task_idx        ON agent_runs (task_id, started_at DESC);
CREATE INDEX agent_run_instance_idx    ON agent_runs (agent_instance_id, started_at DESC);
CREATE INDEX agent_run_definition_perf_idx
  ON agent_runs (agent_definition_id, outcome, completed_at DESC);

-- Structured findings emitted by a run (queryable knowledge)
CREATE TABLE agent_findings (
  finding_id          ulid PRIMARY KEY,
  organization_id     ulid NOT NULL REFERENCES identity.organizations(organization_id),
  run_id              ulid NOT NULL REFERENCES agent_runs(run_id) ON DELETE CASCADE,
  mission_id          ulid NOT NULL REFERENCES missions.missions(mission_id) ON DELETE CASCADE,

  claim               TEXT NOT NULL,
  epistemic_status    epistemic_status NOT NULL,
  confidence          confidence_score NOT NULL,

  evidence_refs       TEXT[] NOT NULL DEFAULT '{}',    -- evidence_id[]
  contradicts_refs    TEXT[] NOT NULL DEFAULT '{}',    -- finding_id[]

  created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX finding_mission_status_idx ON agent_findings (mission_id, epistemic_status);
CREATE INDEX finding_claim_trgm_idx     ON agent_findings USING gin (claim gin_trgm_ops);

-- First-class Decision records (Article XIII §37)
CREATE TABLE decisions (
  decision_id         ulid PRIMARY KEY,
  organization_id     ulid NOT NULL REFERENCES identity.organizations(organization_id),
  project_id          ulid REFERENCES projects.projects(project_id),
  mission_id          ulid REFERENCES missions.missions(mission_id),
  run_id              ulid REFERENCES agent_runs(run_id),

  decision_number     INT NOT NULL,                    -- human-friendly per-project
  question            TEXT NOT NULL,
  options             JSONB NOT NULL,                  -- [{name, description, tradeoffs}]
  selected_option     TEXT NOT NULL,

  evidence            JSONB NOT NULL DEFAULT '[]'::jsonb,
```

```sql
-- ═══════════════════════════════════════════════════════════════════
-- SCHEMA: memory — 7 memory scopes with provenance & vector search
-- ═══════════════════════════════════════════════════════════════════
SET search_path TO memory, public;

CREATE TABLE memories (
  memory_id           ulid PRIMARY KEY,
  organization_id     ulid NOT NULL REFERENCES identity.organizations(organization_id),

  -- scope binding (nullable per scope semantics)
  user_id             ulid REFERENCES identity.users(user_id),
  project_id          ulid REFERENCES projects.projects(project_id),
  mission_id          ulid REFERENCES missions.missions(mission_id),
  conversation_id     ulid,

  -- semantic triple structure (subject/predicate/value)
  subject             TEXT NOT NULL,
  predicate           TEXT NOT NULL,
  value               TEXT NOT NULL,
  value_structured    JSONB,                            -- for typed values

  -- PROVENANCE (Law 3: no memory without lineage)
  source              TEXT NOT NULL,                    -- 'user','agent','tool','research','decision'
  source_ref          TEXT,                             -- URI/ID pointing at origin
  written_by_agent    TEXT,                             -- agent_definition_id
  written_by_run      ulid REFERENCES agents.agent_runs(run_id),
  citations           JSONB NOT NULL DEFAULT '[]'::jsonb,

  -- QUALITY
  confidence          confidence_score NOT NULL DEFAULT 0.8,
  evidence_count      INT NOT NULL DEFAULT 0,
  contradicts_ids     ulid[] NOT NULL DEFAULT '{}',
  supersedes_ids      ulid[] NOT NULL DEFAULT '{}',

  -- LIFECYCLE
  version             INT NOT NULL DEFAULT 1,
  status              memory_status NOT NULL DEFAULT 'active',
  expires_at          TIMESTAMPTZ,
  importance          confidence_score NOT NULL DEFAULT 0.5,

  -- ACCESS
  visibility          TEXT NOT NULL DEFAULT 'project'
                      CHECK (visibility IN ('private','project','organization','public')),
  sensitivity         sensitivity NOT NULL DEFAULT 'internal',

  -- VECTOR (multi-dim: 1536 for OpenAI, 1024 for cohere, etc.)
  embedding_1024      vector(1024),                     -- primary retrieval space
  embedding_model_id  TEXT,                             -- which model produced it

  created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),

  -- scope-binding integrity
  CHECK (
    (scope = 'working'        AND mission_id IS NOT NULL) OR
    (scope = 'conversation'   AND conversation_id IS NOT NULL) OR
    (scope = 'episodic'       ) OR
    (scope = 'semantic'       ) OR
    (scope = 'procedural'     ) OR
    (scope = 'project'        AND project_id IS NOT NULL) OR
    (scope = 'organizational' )
  )
);

-- Retrieval indexes
CREATE INDEX mem_scope_active_idx     ON memories (organization_id, scope)
  WHERE status = 'active';
CREATE INDEX mem_project_active_idx   ON memories (project_id, status)
  WHERE project_id IS NOT NULL;

  WHERE status = 'active' AND mission_id IS NOT NULL;

CREATE INDEX mem_value_trgm_idx       ON memories USING gin (value gin_trgm_ops);
CREATE INDEX mem_recency_idx          ON memories (organization_id, created_at DESC);

  ON memories USING hnsw (embedding_1024 vector_cosine_ops)
  WITH (m = 16, ef_construction = 64);

-- Working memory has TTL cleanup
CREATE INDEX mem_expiry_idx ON memories (expires_at)
  WHERE expires_at IS NOT NULL AND status = 'active';

-- Context packets (compiled by A4 for a specific run; short-lived)
CREATE TABLE context_packets (

  packet_uri          TEXT NOT NULL,                    -- object store URI
  packet_hash         sha256_hex NOT NULL,
```

```sql
  embedding_1024      vector(1024),
```

## 17. ROW-LEVEL SECURITY (MULTI-TENANT ISOLATION)

Every tenant-scoped table has RLS enabled. The application sets `SET LOCAL app.current_org = 'org_ulid'` at the start of each transaction.

```sql
-- ═══════════════════════════════════════════════════════════════════
-- ROW-LEVEL SECURITY — Enforced tenant isolation on every read/write
-- ═══════════════════════════════════════════════════════════════════

-- Helper function used by all policies
CREATE OR REPLACE FUNCTION current_org_id() RETURNS ulid
LANGUAGE sql STABLE AS $$
  SELECT current_setting('app.current_org', true)::ulid
$$;

-- Apply RLS pattern to every tenant-scoped table
DO $$
DECLARE
  t RECORD;
BEGIN
  FOR t IN
    SELECT n.nspname AS schema_name, c.relname AS table_name
    FROM pg_class c
    JOIN pg_namespace n ON n.oid = c.relnamespace
    JOIN pg_attribute a ON a.attrelid = c.oid
    WHERE c.relkind = 'r'
      AND a.attname = 'organization_id'
      AND n.nspname IN ('projects','missions','agents','tools','memory','brain',
                        'research','artifacts','verification','security',
                        'events','evolution','billing')
  LOOP
    EXECUTE format('ALTER TABLE %I.%I ENABLE ROW LEVEL SECURITY', t.schema_name, t.table_name);
    EXECUTE format('ALTER TABLE %I.%I FORCE ROW LEVEL SECURITY', t.schema_name, t.table_name);
    EXECUTE format(
      'CREATE POLICY tenant_isolation ON %I.%I
         USING (organization_id = current_org_id())
         WITH CHECK (organization_id = current_org_id())',
      t.schema_name, t.table_name
    );
  END LOOP;
END $$;

-- coco_app role is subject to RLS; coco_owner is bypass for migrations
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA
  projects, missions, agents, tools, memory, brain, research,
  artifacts, verification, security, events, evolution, billing
  TO coco_app;

ALTER ROLE coco_app SET row_security = on;
ALTER ROLE coco_owner BYPASSRLS;
```

**Application contract:**

```sql
-- At the start of every transaction serving a request:

SET LOCAL app.current_org = 'org_01J8XZ...';
SET LOCAL app.current_user = 'usr_01J8XZ...';
-- ... queries run here; RLS filters automatically ...
COMMIT;
```

## 19. TRIGGERS & CONSTRAINTS (Constitutional Enforcement)

```sql
-- ═══════════════════════════════════════════════════════════════════
-- Triggers enforce Constitutional Laws at the DB layer
-- ═══════════════════════════════════════════════════════════════════

-- updated_at maintenance
CREATE OR REPLACE FUNCTION touch_updated_at() RETURNS TRIGGER LANGUAGE plpgsql AS $$
BEGIN NEW.updated_at = NOW(); RETURN NEW; END $$;

DO $$
DECLARE
  t RECORD;
BEGIN
  FOR t IN
    SELECT n.nspname AS s, c.relname AS r
    FROM pg_class c JOIN pg_namespace n ON n.oid = c.relnamespace
    JOIN pg_attribute a ON a.attrelid = c.oid
    WHERE a.attname = 'updated_at' AND c.relkind = 'r'
      AND n.nspname NOT IN ('pg_catalog','information_schema','partman')
  LOOP
    EXECUTE format(
      'CREATE TRIGGER trg_touch_updated_at BEFORE UPDATE ON %I.%I
         FOR EACH ROW EXECUTE FUNCTION touch_updated_at()',
      t.s, t.r
    );
  END LOOP;
END $$;

-- Enforce Law 2: memories/decisions/events cannot be hard-updated in critical fields
CREATE OR REPLACE FUNCTION guard_memory_immutable_provenance() RETURNS TRIGGER LANGUAGE plpgsql AS $$
BEGIN
  IF NEW.source <> OLD.source
     OR NEW.written_by_agent <> OLD.written_by_agent
     OR NEW.written_by_run   IS DISTINCT FROM OLD.written_by_run THEN
    RAISE EXCEPTION 'Memory provenance is immutable (Law 2/3); create a new memory record instead';
  END IF;
  RETURN NEW;
END $$;

CREATE TRIGGER trg_guard_memory_immutable
BEFORE UPDATE ON memory.memories
FOR EACH ROW EXECUTE FUNCTION guard_memory_immutable_provenance();

-- Enforce Law 4: mission_id required on any run/task/artifact tying back to work
-- (already enforced via NOT NULL + FK; documented here)

-- Enforce Law 9: reject oversized JSONB payloads at the DB boundary
CREATE OR REPLACE FUNCTION reject_oversized_jsonb(field JSONB, max_kb INT) RETURNS VOID LANGUAGE plpgsql AS $$
BEGIN
  IF octet_length(field::text) > (max_kb * 1024) THEN
    RAISE EXCEPTION 'JSONB payload exceeds % KB; store as artifact and reference by URI', max_kb;
  END IF;
END $$;

CREATE OR REPLACE FUNCTION guard_event_data_size() RETURNS TRIGGER LANGUAGE plpgsql AS $$
BEGIN PERFORM reject_oversized_jsonb(NEW.data, 64); RETURN NEW; END $$;

CREATE TRIGGER trg_guard_event_size
BEFORE INSERT ON events.event_log
FOR EACH ROW EXECUTE FUNCTION guard_event_data_size();
```

## 21. INDEX STRATEGY SUMMARY

```text
INDEX TYPE       WHERE USED                         PURPOSE
────────────    ─────────────────────────────────   ──────────────────────────────
B-tree          FKs, status columns, IDs            Point lookups, joins
BRIN            High-cardinality time columns       Compact time-range scans
GIN (JSONB)     Structured properties, tags         Contains/exists queries
GIN (trgm)      Human text (titles, claims)         Fuzzy substring search
HNSW (vector)   embedding_1024 columns              Approx nearest-neighbor
Partial         status='active' filters             Skip archived rows
Unique          Business keys (slug, hash)          Enforce uniqueness
Composite       (org_id, status, time DESC)         Tenant + hot-list queries

ANTI-PATTERNS EXPLICITLY AVOIDED:
- No indexes on rarely-queried boolean columns
- No duplicate indexes with subset column lists
- No B-tree on high-write timestamp columns (BRIN instead)
- No global indexes on partitioned tables when local suffices
```
