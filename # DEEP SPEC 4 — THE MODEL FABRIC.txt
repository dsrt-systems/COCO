## 0. MODEL FABRIC PHILOSOPHY

The Model Fabric is COCO's **substrate abstraction layer**. Its purpose is not to run models — it is to make models **interchangeable, measurable, and routable** so that the rest of COCO never depends on any specific one.

### The Ten Governing Laws of the Model Fabric

```text
LAW 1  — CAPABILITIES, NOT MODELS
         COCO agents request capabilities (reason, code, vision, embed).
         The fabric selects the model. Agents never name a provider.

LAW 2  — ROUTING IS AN EVOLVED CAPABILITY
         Every route decision is recorded. Outcomes feed back into policy.
         The router improves without human tuning.

LAW 3  — PROVIDER-AGNOSTIC ADAPTERS
         Every model — OpenAI, Anthropic, Google, xAI, DeepSeek, Qwen,
         Llama, Mistral, custom fine-tunes, local Ollama, local vLLM —
         speaks the same wire protocol: ModelInferenceRequest.

LAW 4  — NEVER SINGLE-VENDOR-LOCKED
         Every capability has at least 2 providers registered.
         Fallback is automatic and invisible to callers.

LAW 5  — DEADLINE PROPAGATION IS SACRED
         Every inference carries a deadline. Adapters honor it.
         Cascading timeouts are engineering failures, not accidents.

LAW 6  — COST IS FIRST-CLASS
         Every call is priced pre-execution and reconciled post-execution.
         Budget envelopes are enforced, not requested.

LAW 7  — CACHE AGGRESSIVELY, INVALIDATE PRECISELY
         Semantic and exact-match caching are default-on.
         Cache keys include: prompt, params, tools, model_id, org_id.

LAW 8  — LOCAL + HOSTED CO-EXIST
         Local models (Ollama, vLLM) are first-class citizens with the
         same telemetry, SLAs, and routing eligibility as hosted APIs.

LAW 9  — STREAMING BY DEFAULT
         All user-facing inference streams. Non-streaming is the exception.
         Cancellation propagates to the provider, not silently discarded.

LAW 10 — CIRCUIT BREAKERS PROTECT COCO
         Providers fail. Rate limits happen. The fabric degrades gracefully:
         circuit-break, fallback, requeue, or explicitly surface the failure.
```

## 4. THE UNIFIED ADAPTER INTERFACE

Every provider — regardless of API shape — is wrapped in a **ModelAdapter** conforming to a single interface. Adapters normalize inputs, outputs, streaming, errors, and metrics.

### 4.1 Adapter Contract

```python
# coco/model_fabric/adapter.py

from abc import ABC, abstractmethod
from typing import AsyncIterator
from coco.protocol.v1 import (
    ModelInferenceRequest,
    ModelInferenceEvent,
    ExtendedModelDescriptor,
    Endpoint,
    HealthState,
)


class ModelAdapter(ABC):
    """
    Uniform interface across all model providers.
    Implementations MUST be:
      - async-first
      - cancellation-safe (must abort provider request on task cancel)
      - deadline-aware (must not exceed request.deadline_unix_ns)
      - metric-emitting (via injected telemetry sink)
    """

    provider: str                       # e.g. "anthropic", "ollama"
    supported_families: list[str]       # e.g. ["claude"]

    @abstractmethod
    async def infer(
        self,
        request: ModelInferenceRequest,
        endpoint: Endpoint,
    ) -> AsyncIterator[ModelInferenceEvent]:
        """
        Execute inference, yielding streaming events.
        For non-streaming providers, yields a single STREAM_END with full result.
        Adapter is responsible for:
          - Provider-specific auth (via SecretBroker)
          - Provider-specific request shape translation
          - Provider-specific response normalization
          - Retry on transient errors (respecting deadline)
          - Emitting usage on STREAM_END
        """

    @abstractmethod
    async def embed(
        self,
        texts: list[str],
        model_id: str,
        endpoint: Endpoint,
    ) -> list[list[float]]:
        """Batch embedding. Returns vectors in the same order as inputs."""

    @abstractmethod
    async def rerank(
        self,
        query: str,
        documents: list[str],
        model_id: str,
        endpoint: Endpoint,
    ) -> list[tuple[int, float]]:
        """Return (original_index, score) pairs sorted desc by score."""

    @abstractmethod
    async def health_check(self, endpoint: Endpoint) -> HealthState:
        """Lightweight liveness probe — used by the health poller."""

    @abstractmethod
    def estimate_tokens(self, text: str, model_id: str) -> int:
        """Cheap token estimate (adapter caches tokenizers)."""

    @abstractmethod
    def estimate_cost(
        self,
        input_tokens: int,
        estimated_output_tokens: int,
        model_id: str,
    ) -> float:
        """USD cost estimate; used by Router for budget checks."""
```

### 4.2 Adapter Registry

```python
class AdapterRegistry:
    """
    Discovers and instantiates adapters. One adapter class per provider.
    Adapters are loaded at boot and pinned in memory (they hold connection pools).
    """

    def __init__(self):
        self._adapters: dict[str, ModelAdapter] = {}

    def register(self, adapter: ModelAdapter) -> None:
        self._adapters[adapter.provider] = adapter

    def get_for_model(self, descriptor: ExtendedModelDescriptor) -> ModelAdapter:
        adapter = self._adapters.get(descriptor.provider)
        if not adapter:
            raise UnknownProviderError(descriptor.provider)
        if descriptor.family not in adapter.supported_families:
            raise UnsupportedFamilyError(descriptor.family, adapter.provider)
        return adapter

    def all(self) -> list[ModelAdapter]:
        return list(self._adapters.values())
```

### 4.3 Reference Adapter — Anthropic

```python
class AnthropicAdapter(ModelAdapter):
    provider = "anthropic"
    supported_families = ["claude"]

    def __init__(self, secret_broker, http_client, telemetry, tokenizer_cache):
        self._secrets = secret_broker
        self._http = http_client            # httpx.AsyncClient with connection pool
        self._telemetry = telemetry
        self._tokenizers = tokenizer_cache

    async def infer(self, request, endpoint):
        api_key = await self._secrets.fetch(endpoint.credential_secret_ref)
        body = self._translate_to_anthropic(request)      # normalize protocol → provider shape
        deadline_ms = self._deadline_ms(request)

        started = time.time_ns()
        input_tokens = self._count_input_tokens(request)

        try:
            async with self._http.stream(
                "POST",
                f"{endpoint.base_url}/v1/messages",
                headers={
                    "x-api-key": api_key,
                    "anthropic-version": "2023-06-01",
                    "content-type": "application/json",
                },
                json=body,
                timeout=self._timeout(deadline_ms),
            ) as response:
                if response.status_code == 429:
                    raise RateLimitError(retry_after_ms=self._parse_retry_after(response))
                if response.status_code >= 500:
                    raise ProviderUnavailableError(response.status_code)
                response.raise_for_status()

                output_tokens = 0
                async for line in response.aiter_lines():
                    event = self._parse_anthropic_sse(line)
                    if event is None:
                        continue
                    if event.kind == StreamEventKind.CONTENT_DELTA:
                        output_tokens += self._estimate_delta_tokens(event.text_delta)
                    yield event

                # Final usage event
                yield ModelInferenceEvent(
                    inference_id=request.inference_id,
                    kind=StreamEventKind.STREAM_END,
                    usage_snapshot=TokenUsage(
                        input_tokens=input_tokens,
                        output_tokens=output_tokens,
                        cost_usd=self.estimate_cost(input_tokens, output_tokens, request.model_id),
                    ),
                )
        except asyncio.CancelledError:
            # Ensure provider connection is torn down; do not swallow
            raise
        finally:
            self._telemetry.record_inference(
                inference_id=request.inference_id,
                model_id=request.model_id,
                provider=self.provider,
                endpoint=endpoint.endpoint_id,
                started_ns=started,
                completed_ns=time.time_ns(),
                input_tokens=input_tokens,
                output_tokens=output_tokens,
            )
```

**Adapters for OpenAI, Google, xAI, DeepSeek, Mistral, Ollama, vLLM, and llama.cpp** follow the identical shape. Only the translation layer and response parsing differ.

### 4.4 Local Adapter — vLLM (OpenAI-compatible)

```python
class VLLMAdapter(ModelAdapter):
    """
    vLLM exposes an OpenAI-compatible endpoint. We inherit the OpenAI adapter
    translation and override only auth, endpoint discovery, and health.
    """
    provider = "vllm"
    supported_families = ["qwen", "llama", "mistral", "deepseek", "custom"]

    async def health_check(self, endpoint):
        # vLLM exposes /health returning 200 OK when ready
        try:
            r = await self._http.get(f"{endpoint.base_url}/health", timeout=2.0)
            return HealthState.HEALTHY if r.status_code == 200 else HealthState.DEGRADED
        except Exception:
            return HealthState.UNAVAILABLE

    def estimate_cost(self, input_tokens, output_tokens, model_id):
        # Local models: incremental cash cost = 0. Accounting cost tracked in GPU pool.
        return 0.0
```

### 4.5 Adapter Error Taxonomy (normalized to `CocoError`)

```text
PROVIDER-RAW              →   NORMALIZED CocoError
─────────────────────────    ────────────────────────────────
HTTP 401/403              →   category=PERMISSION, retryable=false
HTTP 429                  →   category=NETWORK, retryable=true, retry_after_ms set
HTTP 500/502/503/504      →   category=NETWORK, retryable=true, retry_after_ms=exp
HTTP 400 (bad_request)    →   category=LOGIC, retryable=false
HTTP 413 (too_large)      →   category=REQUIREMENT, retryable=false
Timeout                   →   category=NETWORK, retryable=true
Cancelled                 →   category=UNKNOWN, retryable=false
Content filter            →   category=SECURITY, retryable=false
Context length exceeded   →   category=REQUIREMENT, retryable=false
Model not found           →   category=CONFIG, retryable=false
```

The Router treats retryable errors as **transient** and applies fallback logic; non-retryable errors are surfaced immediately.

## 5. THE ROUTER — DECISION ENGINE

### 5.3 Utility Function (Reference Implementation)

```python
def compute_utility(
    candidate: ExtendedModelDescriptor,
    capability_id: str,
    hints: RoutingHints,
    hint_weights: WeightVector,
) -> UtilityScore:
    """
    Utility ∈ [0, 1]. Higher is better.
    Weights come from QualityFloor / hints:
      MAXIMUM  → (q=0.7, l=0.1, c=0.05, a=0.15)
      EXCELLENT→ (q=0.55, l=0.15, c=0.15, a=0.15)
      GOOD     → (q=0.35, l=0.25, c=0.25, a=0.15)
      ACCEPTABLE → (q=0.20, l=0.30, c=0.35, a=0.15)
    """
    binding = _find_binding(candidate, capability_id)
    quality = binding.observed_quality_score or binding.declared_quality_score

    perf = candidate.observed
    latency_score = _normalize_latency(perf.p95_latency_ms, hints.max_latency_ms)
    cost_est = _estimate_cost(candidate, capability_id)
    cost_score = _normalize_cost(cost_est, hints.max_cost_usd)
    availability = perf.success_rate * _health_multiplier(candidate)

    w = hint_weights
    utility = (
        w.quality * quality
        + w.latency * latency_score
        + w.cost * cost_score
        + w.availability * availability
    )
    return UtilityScore(
        model_id=candidate.model_id,
        utility=utility,
        components={
            "quality": quality,
            "latency": latency_score,
            "cost": cost_score,
            "availability": availability,
        },
    )
```

### 5.4 Thompson Sampling for Exploration

```python
class ThompsonExplorer:
    """
    Per (capability_id, model_id) we maintain a Beta posterior over
    'this model produces a satisfactory outcome'. Success signals come from:
      - Critic reports (score >= threshold)
      - Verification pass at target level
      - No repair loop triggered

    Sampling gives us principled exploration without pinning traffic
    to a single winner forever. When a new model registers, its prior
    is Beta(2, 2) — mild exploration until data accumulates.
    """

    def sample_utility(self, candidate, base_utility, prior):
        alpha, beta = prior.alpha, prior.beta
        sampled = np.random.beta(alpha, beta)
        # Blend the base utility with the sampled belief, shrinking exploration
        # weight as observation count grows.
        n = alpha + beta - 4  # subtract prior
        exploration_weight = 1.0 / (1.0 + math.log(1 + max(n, 0)))
        return (1 - exploration_weight) * base_utility + exploration_weight * sampled
```

### 5.5 Fallback Chains

Every `ModelRouteDecision` carries a `fallback_chain: list[str]` — an ordered list of model IDs to try if the primary fails.

```python
def build_fallback_chain(
    ranked_candidates: list[UtilityScore],
    primary_id: str,
) -> list[str]:
    """
    Fallback rules:
      1. Prefer different providers (avoid correlated failures).
      2. Prefer same tier or lower (avoid quality regression).
      3. Include at least one local model if any exist in candidates
         (last-resort availability guarantee).
      4. Cap chain length at 3 (compound latency budget).
    """
    primary = _lookup(primary_id)
    seen_providers = {primary.provider}
    chain: list[str] = []

    for cand in ranked_candidates:
        if cand.model_id == primary_id:
            continue
        desc = _lookup(cand.model_id)
        if desc.provider not in seen_providers:
            chain.append(cand.model_id)
            seen_providers.add(desc.provider)
        if len(chain) == 2:
            break

    # Ensure a local model appears if available
    if not any(_lookup(m).deployment_mode.name.startswith("LOCAL") for m in chain):
        local = _first_local(ranked_candidates)
        if local:
            chain.append(local.model_id)

    return chain[:3]
```

### 5.6 Circuit Breaker

```python
class EndpointCircuitBreaker:
    """
    One breaker per endpoint. Opens after N consecutive failures within a window.
    Half-opens after cooldown; closes on first successful probe.
    """

    def __init__(
        self,
        failure_threshold: int = 5,
        window_seconds: int = 60,
        open_seconds: int = 30,
        half_open_max_probes: int = 3,
    ):
        ...

    async def before_call(self, endpoint_id: str) -> None:
        state = self._state[endpoint_id]
        if state.is_open():
            raise CircuitOpenError(endpoint_id, opens_at=state.reopens_at)
        if state.is_half_open():
            if not state.reserve_probe_slot():
                raise CircuitOpenError(endpoint_id, opens_at=state.reopens_at)

    def record_success(self, endpoint_id: str) -> None: ...
    def record_failure(self, endpoint_id: str, category: ErrorCategory) -> None: ...
```

**Circuit-open events** feed the health poller, which updates `EndpointHealth.circuit_breaker_open_until_unix_ns`. The Router then filters that endpoint from Stage 2 automatically.

### 7.1 Two-Tier Cache Architecture

```text
                     ┌──────────────────────┐
                     │  ModelRouteRequest   │
                     └──────────┬───────────┘

                                ▼
                     ┌──────────────────────┐
                     │  L1: EXACT-MATCH     │

                     │    prompt, params,   │
                     │    tools, model_id,  │
                     │    org_id)           │
                     └──────────┬───────────┘
                       Miss     │  Hit → return cached
                                ▼
                     ┌──────────────────────┐
                     │  L2: SEMANTIC        │
                     │  pgvector, TTL=24h   │
                     │  Cosine sim > 0.98   │
                     │  Same org + model    │
                     └──────────┬───────────┘

                     ┌──────────────────────┐
```

### 7.2 Cache Correctness Rules

```text
NEVER CACHE WHEN:
  - request.params.temperature > 0.1        (non-deterministic requested)
  - request.params.seed is unset AND temp > 0
  - capability ∈ {vision.ocr on live PDFs, research.extract on live URLs}
  - agent has instructed "no_cache" hint
  - sensitivity == RESTRICTED (unless per-org opt-in)
  - tool-augmented reasoning with tool state dependencies

INVALIDATION:
  - Prompt template version change    → invalidate all keys using that template
  - Model deprecation                 → drop all entries for that model_id
  - Org-level "flush cache" action    → drop all entries for that org_id
  - Tenant data-residency change      → drop all entries in old region

WRITE PATH:
  - Populate L1 on every successful completion (async, non-blocking)
  - Populate L2 with embedded prompt on completion
  - Store {response, provenance, cost_saved, hit_count}
```

```python
def compute_cache_key(request: ModelInferenceRequest, org_id: str) -> str:
    canonical = {
        "org_id": org_id,
        "model_id": request.model_id,
        "messages": _normalize_messages(request.messages),
        "params": {
            "temperature": request.params.temperature,
            "top_p": request.params.top_p,
```

## 9. STREAMING, CANCELLATION, DEADLINE PROPAGATION

### 9.1 Streaming Coordination

```text
Client (UI / Kernel)
       │  gRPC bidi stream
       ▼
Intelligence Service.InferModel  ──── stream: ModelInferenceEvent
       │
       ▼
Adapter.infer                    ──── HTTP SSE / WebSocket to provider
       │
       ▼
Provider
```

Every layer supports:
- **Backpressure**: consumer-driven flow control (async iterator pull)
- **Cancellation**: `asyncio.CancelledError` propagates from client → adapter → provider abort
- **Deadline**: `deadline_unix_ns` threaded through every layer; adapter refuses to start a new inference if remaining_ms < min_viable_ms

### 9.2 Cancellation Contract

```python
async def stream_from_router(request):
    async with router.route_and_stream(request) as stream:
        try:
            async for event in stream:
                yield event
        except asyncio.CancelledError:
            # This automatically triggers adapter's HTTP client to abort the
            # underlying provider request. Adapter guarantees:
            #   - open TCP connection is closed
            #   - reservation is released back to rate limiter
            #   - partial usage is recorded to model_calls with status=cancelled
            raise
```

### 9.3 Deadline Enforcement

```python
def enforce_deadline(deadline_unix_ns: int, min_viable_ms: int = 500):
    remaining_ns = deadline_unix_ns - time.time_ns()
    if remaining_ns < min_viable_ms * 1_000_000:
        raise DeadlineExceededError(
            "Insufficient time remaining to attempt inference"
        )
    return remaining_ns / 1_000_000  # returns ms for adapter timeout
```

## 10. COST GOVERNANCE

### 10.1 Envelope Enforcement

Every mission carries a `ResourceBudget`. Every inference is:
1. **Estimated** pre-call (`adapter.estimate_cost`)
2. **Deducted** from the mission's remaining envelope atomically
3. **Reconciled** post-call with actual usage

```python
class BudgetEnforcer:
    async def try_reserve(
        self,
        mission_id: str,
        estimated_cost_usd: float,
        estimated_tokens: int,
    ) -> BudgetReservation:
        """
        Atomic Redis operation:
          if remaining_budget >= estimated_cost:
            deduct, return Reservation(reservation_id, deducted_amount)
          else:
            raise BudgetExhaustedError

        The reservation is a hold. On completion, `reconcile()` adjusts
        the deducted amount to actual cost (refund overestimate, or
        emit `mission.budget_warning` on underestimate).
        """
```

### 10.2 Tier-Envelope Defaults

```text
TIER          MODEL COST         MAX MODEL          NOTES
              PER MISSION        TIER
────────      ────────────      ─────────           ───────────────────────
DEFAULT       $0.25              ADVANCED           Local models preferred
PRO           $5.00              FRONTIER           Full fabric access
RANGER        $100.00            FRONTIER           Configurable per mission
ENTERPRISE    Contract-defined   Private/Custom     Dedicated capacity
```

### 10.3 Budget Warnings

Events emitted:
- `mission.budget_warning` at 50%, 75%, 90% consumption
- `mission.budget_exceeded` at 100% → mission enters `BLOCKED` state pending user action

The Router **degrades gracefully** as budget approaches exhaustion: quality weights shift toward cheaper models, exploration ε drops, and cache hits are aggressively preferred.

### 15.3 Cold Start Mitigation

```text
STRATEGIES:
  1. Pin popular models in the warm pool (never evict)
  2. Predictive preloading based on scheduled missions
  3. Deadline-aware routing: skip local models if load time > remaining budget
  4. Progressive fallback: try warm local → cold local → hosted
  5. Model quantization tier: FP16 pinned, FP8 on-demand, GGUF for burst
```

### 16.2 Evaluation Loop

Fine-tuned models enter the registry with **shadow traffic** (routed 5% of eligible traffic in parallel with production choice). The Evolution Fabric compares outcomes over N missions; if the fine-tune wins on the target capability's quality axis, it graduates to `preferred: true` in its capability binding.
